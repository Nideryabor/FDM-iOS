## 一、★★ 最严重：拖动条"坏了"的真凶

```objc
// v71（错的）
UILongPressGestureRecognizer *lp = ...;
lp.minimumPressDuration = 0.18;
lp.allowableMovement = 8.0;      // ← 这个值的含义是：
                                 //   手指移动超过 8pt 就 **取消手势**
```

**`allowableMovement` 不是"允许多少抖动"，是"超过多少就 fail"。**

所以手指一动 → `state = Cancelled` → 永远拖不起来。
表现就是：**按下去有点反应（Haptic/高亮），但一动就没了。**

```objc
// v72（对的）
lp.minimumPressDuration = 0.12;
lp.allowableMovement = CGFLOAT_MAX;   // ★ 不限制
lp.cancelsTouchesInView = NO;
```

另外 v71 的幽灵只跟 `y`，x 不动 —— 就算拖起来看着也像"卡住"。现在跟 y（横拖没意义，列表是竖的）。

顺带加了：**边缘自动滚**（拖到顶部/底部 80pt 内自动滚列表）。

## 二、展开内容错位（截图 2 能直接看出来）

```objc
// v71（错的）
- (CGFloat)tableView:heightForRowAtIndexPath:(NSIndexPath *)ip {
    PUCell *c = (PUCell *)[tv cellForRowAtIndexPath:ip];   // ← 拿到 nil！
    return (c && c.expanded) ? 132.0 : 62.0;
}
```

`cellForRowAtIndexPath:` 在 cell 还没创建时返回 **nil**，
于是永远返回 62 —— 但 cell 内部按 `expanded=YES` 排了多行内容，
**内容就溢出到下一行上**（截图 2 里"富文本"的正文盖到了"系统设置"上）。

```objc
// v72（对的）
// 展开状态存在 VC 里，按 key 存
NSMutableSet<NSString *> *_expandedKeys;

- (CGFloat)tableView:heightForRowAtIndexPath:(NSIndexPath *)ip {
    const char *key = [self keyAt:ip.section row:ip.item];
    if (!key) return 62.0;
    NSString *ks = [NSString stringWithUTF8String:key];
    return [_expandedKeys containsObject:ks] ? 168.0 : 62.0;
}
```

> **铁律**：`heightForRow` 里**绝不能**调 `cellForRowAtIndexPath:`
> —— 它会在测量阶段返回 nil，导致高度和内容对不上。

## 三、UI 偏移（预览条压导航栏）

```objc
// v72 加这一行
self.edgesForExtendedLayout = UIRectEdgeNone;
self.extendedLayoutIncludesOpaqueBars = NO;
```

不加的话 `self.view.frame.origin` 在导航栏**下面**，子视图按 view 的 0 点排
⇒ 预览条就跑到导航栏标题上去了（截图 1 里"重置"和预览文字叠在标题行）。

再加一层保险：**预览条改成 `tableHeaderView`** —— 它跟着列表滚，
永远不会压到导航栏。

## 四、卡片点击的三种情况

v71 的问题：中间点击被"展开"独占，想跳页只能点右边小 ▸。

v72 明确分工 —— **中间永远是"展开/收起"，右边永远是"打开"**：

| 卡片类型 | 中间点击 | 右边 ▸（容器里） | 右边 ＋（抽屉里） |
|---|---|---|---|
| 内置三张 | 展开看**约定原文** | 跳对应设置页 | 移入容器 |
| 自定义卡 | 展开看**正文** | 打开编辑弹窗 | 移入容器 |
| 源卡 | 展开看**说明** | 提示怎么用 | 复制一张新的 |

这样"看到内容"和"去改它"彻底分开，不会互相抢。

## 九、给下次的三句话

> **1. `allowableMovement` 是"超过就取消"，不是"容忍抖动"。**
> 想让它一直跟手，就设 `CGFLOAT_MAX`。
> 这个坑的名字很有迷惑性 —— 看名字以为是"允许移动多少"。

> **2. `heightForRow` 里调 `cellForRowAtIndexPath:` 是错的。**
> 测量阶段 cell 还没创建，返回 nil，高度和内容就对不上，
> 表现是"内容溢出盖到下一行"。

> **3. 「看到」和「去改」要分给两个不同的手势。**
> 中间点击 = 展开看内容（只读）
> 右边按钮 = 打开编辑 / 跳页面（可写）
> 混在一起就会互相抢，用户会觉得"点了没反应"。
