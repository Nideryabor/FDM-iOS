## 二、为什么走 UI 层（而不是网络层）

之前 `FDMUserMeta` 的设计是改 `/api/v0/users/current` 的响应。
这次一查，两条路都是死的：

| 查证 | 结果 |
|---|---|
| MMKV `currentUser` | 只有 `settingsToken`，**没有头像字段** |
| `/api/v0/users/current` 请求 | 这台设备**一次都没请求过**（日志 `HandleReq` 全量统计里没有） |

⇒ 网络层改响应根本无从下手。

**真正的位置**（类表 + 视图树实锤）：

```
_TtCC13DeepSeek_Chat25SessionListViewController10FooterView  f=(0,674 326x62)
  ivar[5]: avatar  contextListeners  avatarUrl  dots  nameLabel
  子视图:
    UIImageView  f=(16,14 33x33)          ← 头像
    UILabel      f=(64,19 208x25)  「158******15」  ← 名字（不碰）
    AutoStackLayout f=(288,21 22x20)      ← 那三个点
```

### 做法

hook `FooterView` 的 `layoutSubviews`，布局完把 `avatar.image` 换成我们的图：

- 宿主自己刷新（换 avatarUrl、重新下载）之后，下一次布局又会被盖上去 ⇒ **不会闪回原头像**
- 完全不碰 `nameLabel` ⇒ 名字保持宿主原样（主人明确要求）
- 找不到 `avatar` ivar 就安静退出 ⇒ 版本一换也不会崩

## 三、这轮踩的四个坑

### 坑 1：Swift 类的 ivar 要用 `class_getInstanceVariable`

```objc
Ivar iv = class_getInstanceVariable(object_getClass(footer), "avatar");
id a = object_getIvar(footer, iv);
```

类表 dump 里 `ivar[5] avatar …`，名字就是 `avatar`，能直接拿到（实测成功）。

### 坑 2：`layoutSubviews` 子类**没实现**，必须 `class_addMethod`

类表实锤 FooterView 只实现了 `init` / `initWithCoder:` / `initWithFrame:`。

如果直接 `method_setImplementation(class_getInstanceMethod(c, sel))`，
拿到的是 **UIView 的 Method** ⇒ 改它 = **全局污染所有 UIView**（灾难）。

⇒ 必须判断「这个类自己有没有实现」，没有就 `class_addMethod` 到子类：

```objc
BOOLean hasOwn = /* 扫 class_copyMethodList */;
if (hasOwn) method_setImplementation(m, imp);
else        class_addMethod(c, s, imp, types);   // 父类一动不动
```

日志里 `自有实现=0` 就是这个判断的结果。

### 坑 3：hook 装得太晚，`layoutSubviews` **永远不会再触发**

启动 6 秒后才装 hook，此时 footer 早就布局完了；
它是 collectionView 的 footer，尺寸由父级决定，**不会再自己 layout**。

⇒ 光 hook 不够，必须**主动扫**：

```
hook 成功 → 立刻扫一遍
         → 之后每 2 秒扫一次，最多 30 秒
```

扫描按类名后缀 `SessionListViewController10FooterView` 匹配，命中就换图。

### 坑 4：又是「并行执行」——配置没生效

第一次写 `fdm-avatar.json` 和跑 `cyc.sh` **在同一个消息里并行发出**，
结果 App 重启时 json 还没写完 ⇒ 读到 `enabled=0`。

> 教训：**写配置和重启必须串行**。已经踩过不止一次了。

## 四、怎么用

```json
// Documents/fdm-avatar.json

// ① 本地文件（放在 Documents 里）
{ "enabled": true, "url": "", "file": "fdm-avatar.png" }

// ② 远程 URL
{ "enabled": true, "url": "https://example.com/a.png", "file": "" }
```

改完**重启 App** 生效（目前还没做热重载）。

图片建议 ≥ 200×200 的正方形，会被裁成圆形。
