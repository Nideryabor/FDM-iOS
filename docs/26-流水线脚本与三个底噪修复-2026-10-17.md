## 一、`tools/cyc.sh` —— 七步压成一条命令

以前的迭代是手敲七下，最容易犯的错是**编译和部署并行跑**
（dep.sh 拿到上一版产物，测了半天旧代码，今晚踩了两次）。

```bash
bash tools/cyc.sh -t v5 -c 1 -g 'sug|补扫'
```

| 步 | 做什么 | 失败就停在 |
|---|---|---|
| 1 | `make`，检查 `error:` 与产物 mtime | exit 1 |
| 2 | `dep.sh`（上传 + ldid + 回读） | exit 2 |
| 3 | 设备端 `ls -l` 回读，本地 + 签名 = 设备 | exit 3 |
| 4 | kill → launch → 确认在前台（7P 上会重试一次） | exit 4 |
| 5 | 侧栏 → 第 N 个会话 | — |
| 6 | 截图到 `tmp/mcp-out/<tag>.png` | exit 5 |
| 7 | `grep` 设备日志并截断 160 列 | — |

细节：

- `device_size()` **重试三次**（MCP 偶发超时/锁屏会把 `ls` 打空）
- `make` 认为无需重编时，先比「设备上是不是就是这份」——
  是就跳过部署继续跑，不是才报错
- `-l D` 顺手把日志级别热切过去（见下），不用重启

## 二、修复 1：日志级别热切换（终于不折腾了）

**老问题**：改 `log_level` 要重启 App，而那个 json 归 FDMConfig 管，
UI 一保存就可能被回写 —— 所以「改了没效果」。

**新做法**：FLog 自己每 ~2 秒 `stat` 一个独立小文件。

```
Documents/fdm-log.txt    内容就一个字母：E / W / I / D / T
Documents/fdm-cats.txt   可选，逗号分隔的分类白名单
```

mtime 变了才读，读到立刻生效：

```
22:41:22.488 [W][sys] [log] 级别热切到 D（来自 fdm-log.txt）
22:41:35.102 [W][sys] [log] 级别热切到 W（来自 fdm-log.txt）
```

成本：每 2 秒一次 `stat(2)`。7P 上完全无感。

## 三、修复 2：`[sug-diag]` / `[sug-scan]` 碎日志默认关

之前每 5 秒 18 行 anchor 详情 + 每 4 秒 6 行扫描统计，
7P 上纯白烧 CPU 和磁盘。现在挂到 `FDMSugDiagOn()`：

```bash
echo 1 > Documents/fdm-sugdiag.txt   # 要看的时候开
```

（读一次缓存，不会每轮 stat。）

## 四、修复 3：历史消息「裸奔」——补扫

### 症状

22:41 的截图：消息里明晃晃写着

```
⟦FDM:tip|收费便宜，还管一趟饭，我超划算的⟧
⟦FDM:warn|但火候真的好难控……⟧
<Suggestion>▸ 那你被村民投诉过吗</
Suggestion>
```

而新发的消息是正常的。

### 根因（两个叠一起）

1. **时序**：strip hook 装在启动 **6 秒后**，而 App 在 1~2 秒内
   就把聊天记录从 DB 画到屏幕 ⇒ 那批文字**没经过任何 hook**。
2. **容错不足**：模型真的会写成 `</\nSuggestion>`（换行夹在中间）、
   `⟦/FDM ⟧`（带空格）—— 严格搜字符串必然失败，
   于是「渲染」和「抹除」两条路同时哑火。

### 修法

**A. 补扫（`FDMStripDeepSweep`）**
strip 装完 0.6 秒起做 4 轮（0.6s / 3.6s / 8.6s / 20.6s）：遍历所有
UILabel / UITextView，凡文本里还有标记的，把**已经设好的**
`attributedText` / `text` 再 set 一次 —— 这一次就会经过我们的 wrapper。

```
22:47:50.850 [strip] 补扫 #1：访问 1136 视图，重设 label=0 textview=8
```

**B. 容错闭合标签**
- `SugFindClose()`：找 `</` → 跳空白 → 认 `suggestion` → 跳空白 → 认 `>`
- `FindCloseTolerant()`：`⟦/` → 跳空白 → 认 `FDM` → 跳空白 → 认 `⟧`
- `FDMHasMarks()` 也认 `<Suggestion>`（补扫靠它判定要不要重设）

修完之后同一屏：

| 标记 | 之前 | 现在 |
|---|---|---|
| `⟦FDM:tip\|…⟧` | 原样显示 | 蓝色提示文字 ✓ |
| `⟦FDM:warn\|…⟧` | 原样显示 | 黄底黑字警告框 ✓ |
| `<Suggestion>…</Suggestion>` | 原样显示 + 断行 | 蓝字 + 圆角胶囊 ✓ |

## 五、顺手确认的一件小事

胶囊一开始「看不见」——用红色半透明块做诊断，发现**容器位置完全正确**，
只是 `alpha 0.12 + 0.6px 描边` 在亮色壁纸下根本分辨不出来。

⇒ 调到 `alpha 0.22 + 1.0px 描边(0.8)`，截图确认清晰可见。

> 教训：**「没看见」≠「没画出来」**。先染个不透明色，一次就知道。
