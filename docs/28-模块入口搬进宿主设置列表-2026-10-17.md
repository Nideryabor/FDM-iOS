## 二、为什么能插进去

视图树实锤：**`ProfileViewController.view` 就是那张 `UITableView`**

```
[SCROLL] UITableView f=(0,0 414x696)
  UITableViewWrapperView 16,0 382x696
    _TtCC13DeepSeek_Chat21ProfileViewController17InsetsGroupedCell   ← 宿主的 cell
```

所以可以挂 `tableFooterView`。**为什么选它而不是 hook 数据源**：

| 方案 | 风险 |
|---|---|
| hook `numberOfSections` / `cellForRow` | 会打乱宿主分组、indexPath、section header 高度 |
| **`tableFooterView`** | ✅ 不参与 cell 复用、不碰 indexPath、`reloadData` 也不清 |

样式对着宿主的 `InsetsGroupedCell` 抄：底色 `#282828`、圆角 10、行高 50、左侧 emoji + 17pt 白字 + 右侧 `›`。

宿主自己的 footer（备案号那段）**原样保留**，摞在我们卡片下面。

## 三、这一轮踩到的三个坑（都是"配置关了就整条链断路"）

### 坑 1：`FDMUIInstall` 开头有一颗雷

```objc
// ❌ 旧代码
if (![[FDMConfig shared] boolFor:G_UI key:@"entry_button"]) {
    FLOGI(@"入口按钮已关闭，跳过");
    return;                     // ← 整个 FDMUI 安装都跳过
}
```

我把 `entry_button` 默认改成 NO（改用列表入口）之后，
**连列表入口自己也跑不起来** —— 因为调用它的 `viewWillAppear` hook
正是在 `FDMUIInstall` 里装的。

### 坑 2：`FDMUIInstallRetry` 里有第二颗

```objc
// ❌ 旧代码
if (![[FDMConfig shared] boolFor:G_UI key:@"entry_button"]) return 1;
FDMUIInstall();
```

同一个问题，只是出现在"等 Swift 类 realize 后重试"的定时器里。

**两处都改成**「三个入口（entry_list / entry_button / float_button）全关才跳过」。

### 坑 3：`ProfileViewController.view` 刚出现时是 **0×0 空壳**

```
23:18:48 [bg] 目标 DeepSeek_Chat.ProfileViewController frame={{0, 0}, {0, 0}}
```

真正的表格在 `ProfileViewControllerRoot → UILayoutContainerView → … → UITableView`。
所以在 `viewWillAppear` 那一刻用 `vc.view` 找表格会**找不到**。

三道兜底：
1. `FDMFindTableIn(vc.view, depth ≤ 6)` 递归找
2. 找不到就再试 `parentViewController` / `presentingViewController` 的视图树
3. `tableFooterView.tag` 判重（两个 VC 可能指向同一张表）

### 坑 4（最隐蔽）：FDMUI 整条链**根本没跑**

日志里连「第 N 次尝试」都没有 —— 说明 `FDMUIInstallRetry` 的定时器压根没生效。
与其继续挖（时间成本高），改成**搭车**：

```
FDMComposer 的 0.35s 巡检（一直活着，日志能看到 [sug]）
   └── 每 12 轮（≈4 秒）调一次 FDMUICheckSettingsEntry()
         └── 从 keyWindow 追到最顶层 VC
               └── 类名含 Profile / Setting ⇒ FDMInstallSettingsEntry(vc)
```

这条链已经真机验证稳定（建议按钮的巡检一直在跑）。

## 五、配置

```json
// fdm-ui.json
{
  "entry_list"   : true,    // ★ 设置页列表入口（默认开）
  "entry_button" : false,   // 左上角 🦖（默认关）
  "float_button" : false    // 右下角悬浮（默认关）
}
```

三个都关掉才会跳过 UI hook。
