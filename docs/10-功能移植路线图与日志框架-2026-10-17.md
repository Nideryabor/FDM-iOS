## 一、⭐ 统一日志框架 FLog

### 为什么要专门做一个

之前的日志是**各版本零散拼凑**的，踩过的坑：
| 坑 | 后果 |
|---|---|
| `NSLog` 走 os_log | 远程读不到（`Documents` 里没文件） |
| 刷盘定时器用**局部变量** | 被 ARC 释放 → **日志永远不落盘**（v0.7 的 bug） |
| Hook 内直接写文件 | 阻塞主线程 → 崩溃（v0.2/v0.3） |
| 无轮转 | 沙盒被日志撑爆（v0.2 那 1.88 MB） |

### 设计

```c
FLogWrite(cat, level, fmt, ...)      // 核心，极快
  ├─ 级别过滤（Error/Warn/Info/Debug/Trace）
  ├─ 分类过滤（mmkv/net/inject/ui/cfg/hook/sys/music/call）
  ├─ ① 写内存环形缓冲（NSMutableArray + 环形索引，O(1)）
  └─ ② 追加到待刷盘队列（有上限，防爆内存）
                ↓ 后台每 1 秒
         DoFlush() → 写 fdm.log（超 4MB 轮转 .1）
```

### 铁律落实

| 铁律 | 实现 |
|---|---|
| Hook 内不做 IO | 只做内存 append + `pthread_mutex`（纳秒级） |
| 定时器保活 | `static dispatch_source_t flusher;` |
| 崩溃不丢 | 装 SIGSEGV/SIGBUS/SIGABRT/SIGILL/SIGFPE/SIGTRAP handler → flush → 恢复默认 |
| 不撑爆沙盒 | 4 MB 轮转 |
| 不拖慢 | 时间戳用 `clock_gettime` + `localtime_r`（不用 NSDate） |

### 用法

```c
FLOGE(FC_NET,  @"请求失败 HTTP %ld", code);
FLOGI(FC_INJECT, @"模式=%@ 前缀%lu字", mode, len);
FLOGD(FC_MMKV, @"写 %@ = %@", key, val);     /* Hook 内用 D */
FLOGT(FC_HOOK, @"进入 %s", sel);             /* 最细，排查用 */
```

### ⭐ UI 里能直接看日志

```
FDM 设置 → 调试
  📜 查看日志        1234 条  >   ← 点进去看
  日志文件           fdm.log  >
  清空日志                    >
```

**日志查看器**（`FDMLogViewController`）功能：
- 默认显示最近 600 条，等宽字体
- 「更多」→ 2000 条 / 全部 3000 条 / **只 ERROR+WARN** / **复制全部** / **导出到 Documents**
- 导出文件：`fdm.log.export`（可以直接用 WebDAV 拉走）

### ⚠️ 关键机制：「开关 → 应用入口」（不是裸写存储）

`专题/开关-配置应用入口表.md` 的血泪结论：
> **裸写存储会漏掉两样东西**：功能自己的「读过了」缓存、功能自己的副作用。
> ⇒ 必须走功能自己的入口（`setOn` / `setUOn` / `apply*`）。

**iOS 必须复用这个设计**：配置写入后要触发对应的 apply 动作。
