## 二、⭐ 为什么 iOS 只需要一个落点

安卓要 hook Compose 最深处的 `fz2.p(AnnotatedString)`，
还要重建 `AnnotatedString.Builder` / `SpanStyle` / `Color` 一整套。
**iOS 完全不需要。**

因为宿主的 markdown 渲染链路是：

```
AI 文本
 └─ 宿主 Markdown 解析（SwiftUI / 自研）
     └─ NSAttributedString（成品，带全部样式）
         └─ -[UILabel setAttributedText:]      ★ 必经之路
             ／ -[UITextView setAttributedText:]
```

**所有 markdown 最终都汇到 `setAttributedText:`**，
这和安卓「全部都汇到 `fz2.p`」是同一个道理 —— 但 iOS 这边
拿到的是**标准 `NSAttributedString`**，不需要反射、不需要模仿任何私有类型。

> **方法论**：找「所有渲染路径的收口」比找「每个渲染路径的入口」便宜得多。
> 安卓花了 80KB 代码做的事，iOS 用 24KB 就做完了 —— 因为苹果把富文本标准化了。

## 四、标记语法（与安卓对齐）

```
⟦FDM:模板名⟧                 渲染模板（无参）
⟦FDM:模板名|晴|26℃⟧          渲染模板，{1}=晴  {2}=26℃
⟦FDM⟧<b>内容</b>⟦/FDM⟧       匿名包裹：内部按 HTML 子集渲染
```

### ⚠️ 判定优先级（顺序不能反）

```
① ⟦FDM:xxx⟧      模板模式（有冒号）
② ⟦FDM⟧…⟦/FDM⟧  匿名包裹 → **渲染**（不是删除！）
③ 裸标签模式
④ 残留标记 → 交给 FDMStripMarks 删除
```

**为什么 ② 必须在 ④ 之前**：模型从系统提示词的 `⟦FDM⟧…⟦/FDM⟧`
学了样，会主动写包裹式标记。如果先跑 ④（系统提示词抹除），
AI 写的包裹标记会被当垃圾删掉 ⇒ 玩家永远看不到富文本效果
（安卓原文档的原话：「功能看着只成功一半」）。

## 六、两个关键技术点

### 6.1 字体派生必须保留字体族

```objc
// ❌ 错：丢掉宿主设置的字体族 ⇒「一个字 PingFang 一个字 System」的割裂感
UIFont *bold = [UIFont boldSystemFontOfSize:base.pointSize];

// ✅ 对：用 descriptor 加 trait
UIFontDescriptor *d = base.fontDescriptor;
UIFontDescriptor *nd = [d fontDescriptorWithSymbolicTraits:
                        (d.symbolicTraits | UIFontDescriptorTraitBold)];
UIFont *bold = [UIFont fontWithDescriptor:nd size:base.pointSize];
```

### 6.2 base attributes 从「标记所在位置」取

```objc
NSDictionary *base = [input attributesAtIndex:hitLoc effectiveRange:NULL];
AppendHTML(out, filled, base, 0);
```

不从 `input` 的第 0 位取，而是从**标记实际出现的位置**取 ——
这样「一句话里后半段字号不同」这种宿主特殊排版也能正确继承。

## 七、性能设计（hook 内铁律）

```objc
BOOL FDMRichMaybeAffected(NSString *s) {
    if (!gRichOn || s.length < 4) return NO;
    if ([s rangeOfString:kTplOpen].location != NSNotFound) return YES;
    if ([s rangeOfString:kAnonOpen].location != NSNotFound) return YES;
    if (gBareHTML) { /* 只看 <b> <i> <u> <s> <br <c <bg */ }
    return NO;
}
```

- 99% 的消息没有标记 ⇒ 几次 `rangeOfString` 就返回，**一个字节都不碰**
- 配置**一次性缓存**在静态变量里，hook 内绝不读文件
- `gStReent` 防重入（我们 appendAttributedString 可能再触发 hook）

## 八、怎么用它

### 8.1 手动测试（主人复制不了 ⟦⟧ 时）

把用法写进系统提示词，让 AI 自己用：

```
当你需要强调重点时，按下面的格式输出标记：
⟦FDM:hi|名字⟧ 亮色粗体打招呼
⟦FDM:warn|内容⟧ 黄底黑字警告
⟦FDM:tip|内容⟧ 蓝色提示
⟦FDM:card|标题|内容⟧ 带框卡片
```

然后随便发一句「你好」，AI 就会用标记回复 → 界面直接渲染。

### 8.2 配置（fdm-richtext.json）

```json
{
  "rich_on": true,        // 富文本总开关
  "bare_html": true,      // 裸标签模式（AI 直接写 <b> 也生效）
  "templates": "demo|<b>✦ {1}</b> {2}\ntip|<c6>▸ {1}</c>\n...",
  "c1": "#FF5252", "c2": "#FFB300", ... "c9": "#9E9E9E"
}
```

模板池格式：**每行一条 `名字|HTML`**，`#` 开头是注释，换行用 `<br>`。
