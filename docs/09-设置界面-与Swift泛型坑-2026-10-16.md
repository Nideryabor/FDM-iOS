## 一、⭐ 提示词注入的真凶（重要教训）

### 现象
- `mode=none`（返回原对象）→ ✅ 成功
- `mode=plain`（改 body 后返回）→ ❌ 消息发不出去
- `mode=copy`（只 mutableCopy，不改内容）→ ❌ **一样失败！**
- 自检：`mutableCopy 差异: (无差异)`，`原对象类: NSMutableURLRequest`

### 真凶

```objc
m.HTTPBody = nb;
m.HTTPBodyStream = nil;   // ← 就是这一行！
```

**`NSMutableURLRequest` 里 `HTTPBody` 与 `HTTPBodyStream` 互斥，后设的赢。**

原请求的 `HTTPBodyStream` 是系统从 body **自动派生**的（`HTTPBodyStream` 读出来可能已是 nil，但内部状态是"body 模式"）。一旦显式调用这个 setter，**内部状态被切成"空 stream 模式"** → 请求体变空 → 服务器 **HTTP 400**。

### 修复
```objc
BOOL hadStream = (req.HTTPBodyStream != nil);
NSMutableURLRequest *m = [req isKindOfClass:[NSMutableURLRequest class]]
                         ? (NSMutableURLRequest *)req      // 原地改，最稳
                         : [req mutableCopy];
m.HTTPBody = nb;
// ← 绝不碰 HTTPBodyStream
```

### 附带成果
- 新增**响应诊断**：hook `NSURLSessionTask.error` / `.response` → 抓到 `HTTP 400`
- 新增**失败重放**：自动重发一次拿服务端错误正文（存 `fdm-diag-error.txt`）
- 新增**字节级替换** `PatchPromptInBytes()`：只在原始 JSON 字节里换 prompt 值，
  键序/格式一字不动（比重新序列化安全）

## 二、⭐ Swift 泛型特化的坑（第一次插行为什么误伤别的页）

### 第一次方案
Hook `UITableViewDiffableDataSource` 的泛型特化类，按
**「类名含 `ProfileViewController`」** 匹配：

```
_TtGC5UIKit29UITableViewDiffableDataSourceO
  C13DeepSeek_Chat21ProfileViewController          ← 名字里带着它
  P10$1059a954021SectionIdentifierType...
```

### 为什么错

Swift 泛型特化类的名字**会把类型参数的 owner 写进去**，而
**`ProfileViewController.SectionIdentifierType` 是「设置」页和「账号管理」页共享的枚举类型**。

⇒ **同一个数据源类被两个页面复用**。

我们改 `numberOfSectionsInTableView: → +1`：
- 我们凭空加了一个 section
- 但 diffable 的 **snapshot 只有宿主真实的 section 数**
- ⇒ **快照与 table 状态不一致 → 渲染错乱 → 「账号管理」页的按钮消失**

> 💡 **教训：Swift 泛型特化类名会"蹭"到无关页面，不能按类名模糊匹配。**
> 要可靠地区分实例，得看**运行时对象身份**（如 `tv.delegate` 的类、或实例指针），
> 而不是类名。

## 三、✅ 最终方案：导航栏按钮（零侵入）

```
「设置」页导航栏左上角 → 🦖 按钮
                          ↓ 点击
                    弹出 FDM 设置（原生 UIKit）
```

| 对比 | 数据源方案 | **导航栏方案** |
|---|---|---|
| 碰数据源 | ✅ 改 section/rows/cell | ❌ 完全不碰 |
| 影响面 | ⚠️ 连带其他页面 | ✅ 只有导航栏 |
| 覆盖风险 | — | ✅ **追加不覆盖**（`insertObject:atIndex:0`） |
| 出问题 | 按钮消失 | 最多按钮没出现 |
| 可关闭 | 需重编译 | ✅ `fdm-ui.json {"enabled":false}` |

### Hook 点
```objc

  → IMP 链尾追加：往 navigationItem.leftBarButtonItems 插一个 🦖
```
