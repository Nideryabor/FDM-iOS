## 六、铁律（越靠前越贵）

1. Hook 内只做 O(1) 内存操作，**绝不 IO**
2. Hook 内只读参数指针，**不调宿主方法**
3. `Swap` 必须 `if (old == imp) return NULL`
4. 别碰 `HTTPBodyStream` / `HTTPBody` 的互斥
5. dylib 构造函数里**不能碰 Foundation**
6. 日志**永远 `@"%@"` 包着**
7. 跨函数边界的数据必须 **strong 持有**
8. Swift 泛型特化类匹配必须 `isSubclassOfClass:` 验证
9. 匹配键名要**精确到数字后缀**
10. shell 里别玩单引号嵌套 → **stdin 传脚本**
11. 沙盒只能 `dlopen` `/var/jb/` 下的东西
12. 改完必须**核对产物时间戳**（编译失败时脚本照样出旧包）
13. **「能调通」≠「是对的」**
14. **一次 dump 胜过六次猜测**
15. **「没看见」≠「没画出来」**（先染成不透明色）
16. **开关默认值一改，所有 `if (!开关) return` 都要重审**
17. **拼缝要用同源，不要用调色**
18. **写配置和重启必须串行**（并行会读到旧配置）
19. **`SIGBUS`/`SIGSEGV` 不是异常，`@try` 挡不住** —— 只能靠「不在别人改东西时读」
20. **去重键要含尺寸和对象地址** —— 否则 cell 复用一定漏（配置没变 ≠ 内容没变）
21. **「最大最外层」往往不是你要的那个** —— 锚点要按精确类名找，不要按面积猜
22. **给错误的对象打补丁，会打出 12 个版本** —— 先确认对象，再动手
23. **静态字符串搜不到 ≠ 运行时没有** —— 2.7.1 剥了类名，但运行时全在
24. **对 Swift 类发消息会 SIGTRAP** —— 遍历类表用纯 C：`class_getSuperclass` + 指针比较
25. **不要裸 `alloc` 宿主的 Swift 类** —— `init` 里可能有 `fatalError`
26. **`uiopen 'deepseek://'` 会让 App SIGBUS 崩** —— 空 deeplink 是毒药
27. **`source env.sh` 会污染 gcc** —— 之后跑离线测试 7 套全"编译失败"（`ld64.lld: unknown argument '-plugin'`）。跑测试用干净 shell
28. **中文 ObjC 字面量在 `__TEXT,__ustring`（UTF-16）** —— `strings dylib | grep 中文` 永远 0 命中。自证改动进产物要查符号（`llvm-nm`）或 ASCII 类名
29. **加一个标记族要改三处** —— 定界符常量 / 渲染前的快速闸 / 主扫描循环的 kind 判定。少一处 ⇒ 标记永远不触发
30. **`removeObserver:nil name:...` 拆不掉通知** —— 必须留 token：`gObs = [center addObserverForName:...]`，下次 `removeObserver:gObs`
31. **用 tag 判断控件时绝不能从 0 起** —— `UIView` 默认 tag 就是 0，`tag >= 0 && tag <= 3` 会把每一个默认子视图都当成目标 ⇒ 整卡拖不动。自定义 tag 从 1000 起
32. **`reloadRowsAtIndexPaths` 收到空数组会抛异常** —— 前奏时 `currentRow = -1` ⇒ paths 空 ⇒ 宿主 App 直接被系统杀掉。必须 `if (paths.count)`
33. **缓存键要含"源数据版本"，不能只含对象 id** —— 歌词是异步下载的，只比 `songId` ⇒ 先建了 0 行缓存后再也不重建，界面一片空白
34. **"命令成功但没返回"十成是锁屏了** —— iPhone 锁屏后宿主挂起、dylib 定时器停摆，日志停在那儿不动。**不是崩溃、不是卡死**。遇到先叫主人解锁，别瞎猜（主人 2026-10-25 明确交代）
35. **「小窝测试全过」≠「真机没问题」，尤其是内存 bug** —— gcc 不覆写刚 free 的内存，clang+tcache 会立刻覆写。**测 UAF 必须主动灌垃圾**（分配 200 个同尺寸块）再检查，否则断言永远是假的"通过"（docs/47）
36. **`free` 之后不能再拿原指针** —— `pc_list_remove(..., key)` 内部 free 了 `key`，之后 `pc_box_push(..., key)` 就是 UAF。凡是要跨函数传"从容器里取出来的指针"，**先 strdup**
37. **字符串计数别用 `strlen`** —— 中文 3 字节/字，`strlen("音乐")`=6 但只有 2 个字。界面上一律 `NSString.length`
38. **别用"字符串包含"猜数据结构好坏** —— 正常数据里也会有你以为是"坏特征"的子串（`"tx":""` 既是 v70 bug 的症状也是空正文的合法表示）。**解析 + 校验状态**永远比猜字符串可靠（docs/49）
39. **设了 `leftBarButtonItem` 就等于删掉系统返回键** —— 要自己 pop，并兜底 modal 包裹 / nav 缺失的情况
40. **"防御性代码"本身可能就是 bug 来源** —— 我加的 `suspicious` 检测每进一次页面就把用户卡片清一次，比不保护还糟。保护性代码也要有测试
