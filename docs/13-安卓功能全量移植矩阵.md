## 三、iOS 侧必须遵守的铁律（来自 v0.7 踩坑 + 安卓 13 条）

1. Hook 内**只做 O(1) 内存操作**，绝不 IO（v0.2 崩在 11961 次日志）
2. Hook 内**只读参数指针**，不调宿主方法（MMKV 锁内递归）
3. `Swap` 必须 `if (old == imp) return NULL`（否则无限递归爆栈）
4. 别碰 `HTTPBodyStream` / `HTTPBody` 的互斥（消息发不出去）
5. dylib 构造函数里**不能碰 Foundation**（dyld 阶段 ObjC 未就绪）→ `dispatch_after`
6. 日志**永远 `@"%@"` 包着**（`%@` 传 char* 致命）
7. 跨函数边界的数据必须 **strong 持有**
8. Swift 泛型特化类匹配必须 `isSubclassOfClass:` 验证真实类型
9. 匹配键名要**精确到数字后缀**（`strncmp(c,"modelConfig",11)` 那次的教训）
10. shell 里别玩单引号嵌套 → 用 **stdin 传脚本**
11. 沙盒只能 `dlopen` `/var/jb/` 下的东西（Documents 被 block mmap）
12. 改完必须**核对产物时间戳**（编译失败时脚本照样出旧包）
13. **「能调通」≠「是对的」**
