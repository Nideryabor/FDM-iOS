## 二、这一轮挖出来的「真身」

### 2.1 正文控件根本不是 UILabel

`[sug-tree]` 一次性诊断（新加的，只打 2 次）直接给出层级：

```
_TtGC13DeepSeek_Chat17PlainTextNodeViewOS_23ResponseMarkdownAdapter_  366x264
  ·· _UITextLayoutView            0x0
  ·· _UITextContainerView         366x264
  ·· ·· _UITextViewCanvasView     366x264
```

`_UITextViewCanvasView` 这个名字说明：**它就是个 UITextView 系**。
前面所有版本都在「猜 CoreText 参数」，其实只要 `[tv selectionRectsForRange:]`。

### 2.2 之前的日志在骗自己

旧巡检日志长这样：

```
[sug] ✓ 开始铺（跳过稳定检查，553 字）      ← 每 0.35s × 4 条，刷屏
[sug] ★★ 透明点击层已铺 3 条建议（覆盖 label 366x618）
```

- 「开始铺」刷屏 = 巡检无条件全量重算（浪费）
- 「覆盖 label 366x618」= 覆盖层有 **618 点高**，整个气泡都被吞
- 657 字 / 281 字那两条永远只打「开始铺」不打「已铺」= 它们走的是
  `ParseSuggestions(rawText)` 为 0 的静默 return（渲染后文本里已经没有标签了，
  真正该走的是「按显示文字查注册表」那条路）

## 三、v4 的实现要点（改在 FDMComposer.m / FDMStrip.m）

### 3.1 矩形：三级来源

```objc
BTRectForAnchor(anchor, as, range)
  ① anchor 是 UITextView → -selectionRectsForRange: 取并集（多行也给）
  ② 退 -firstRectForRange:
  ③ 最后才退自算 CoreText（BTRectForRangeAS，用同一份 AS + bounds）
```

### 3.2 矩形要「收高」

行矩形高度 ≈ 30pt，字体 lineHeight ≈ 24pt。
直接用行矩形 ⇒ **上下两颗胶囊互相压住**（实拍确认过）。
现在收到 `ceil(lineHeight) + 4`，横向 `-4/+4`。

### 3.3 每个 anchor 一个框

以前按 `cell.viewWithTag:` 找框 ⇒ 一个 cell 里有两个正文视图时
（思考块 + 回复）互相抢、每 0.35s 打架一次，外观就是「位置一直跳」。
现在 `gSugBoxes`（anchor → box）一对一。

### 3.4 孤儿框清理

`gAllSugBoxes` 强引用所有活着的框，每轮巡检：

```objc
if (!wr.v || !b.window) { [b removeFromSuperview]; }
```

宿主重建正文视图后 anchor 释放 ⇒ 框跟着走，屏上不留残影。

### 3.5 递 AS 的位置也改了

旧代码在 `st_setAttributedText` **开头**就把 `as` 递出去算矩形 ——
但真正显示的是下面的 `clean`（富文本渲染 / 抹除之后）。
⇒ 用 `as` 算 = 必然错位。

现在新增 `STPushSug(anchor, rawString, finalAS)`，
在**两个出口**（rendered 分支 / 结尾）拿最终 `clean` 再递。

### 3.6 顺带清掉的死代码

- `BTScanCellsForSug` 的全树扫描降到每 4 秒（只兜底 UILabel 型正文）
- 「贴 cell 底部补一排真按钮」那段（`cell.height - boxH - 14`）**整段删掉**
  —— 它才是「压在 复制/赞踩 那排上」的元凶
- `FDMRepairSugBoxes` 只剩「清死条目」，不再重建


截图确认：用户气泡 = 「帮人烧荒开田是怎么回事」，AI 正常开始回复。

**顺手修的 bug**：`RenderSuggestion` 里只对 `label` 砍了开头的 `▸`，
`payload` 原封不动 ⇒ 发出去的消息带装饰符。
`FDMRichText.m` 和 `FDMComposer.m` 的 `ParseSuggestions` 两处都补上了。

**长按验证**（22:32）：长按气泡弹的是**宿主原生选中菜单**，
说明「整块吞事件」的问题彻底没了。

**闲置复查**：15 秒内 `★ 铺上` 计数 56 → 56（零 churn）。

> **1. 猜之前先 dump 一层。**
