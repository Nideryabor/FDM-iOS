## 二、⭐ 最大的坑：尼尼一开始误判「装失败了」

### 现象（全是假象）

| 尼尼看到的 | 实际原因 |
|---|---|
| `lsof -i :8090` 无输出 | **设备上没有 `lsof`** |
| `curl 127.0.0.1:8090` 失败 | **设备上没有 `curl`** |
| `/var/mobile/Library/Logs/iOSMCP/` 不存在 | **debug 日志默认关闭**（`isDebugLoggingEnabled` 为假时不写文件） |
| 重启 SpringBoard 没反应 | 其实**一直在正常跑** |

### 真相

从 **Linux 侧**一问就通：

```bash
curl http://192.168.1.6:8090/health
# {"status":"ok","port":8090,"server":"ios-mcp","version":"1.2.8"}
```

> **教训**：在设备上「看不到」≠「没运行」。
> 设备缺命令（lsof/curl/netstat）时，**换到对侧去验证**。

## 三、实际踩过的两个真坑（这两个是真的）

### 3.1 plist 必须是 XML 格式

iOS MCP 的 deb 里，`ios-mcp.plist` 是**二进制 plist**。
这台设备上 FDM 用的是 XML 格式，能正常工作。

```bash
# 检查
head -c 20 /var/jb/usr/lib/TweakInject/ios-mcp.plist

# XML（正确）：<?xml version="1.0" ...
# 二进制（ElleKit 可能不认）：bplist00...
```

**解法**：手写 XML 覆盖（设备上没有 `plutil` 命令）。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
	<key>Filter</key>
	<dict>
		<key>Bundles</key>
		<array>
			<string>com.deepseek.chat</string>
		</array>
	</dict>
</dict>
</plist>
```

### 3.2 Fat 包（多架构）→ 提取单架构

原 deb 里的 dylib 是 **fat binary**（2 个 arm64 切片）：

```
slice0: ARM64 subtype=0x0         offset=0x4000  size=689648
slice1: ARM64 subtype=0x80000002  offset=0xb0000 size=706256  (arm64e)
```

**解法**：用 Python 提取第一个切片（普通 arm64）：

```python
import struct
d = open('ios-mcp.dylib','rb').read()
n = struct.unpack('>I', d[4:8])[0]
for i in range(n):
    off = 8 + i*20
    ct, cs, o, sz, al = struct.unpack('>iiIII', d[off:off+20])
    if ct == 16777228 and cs == 0:      # ARM64 非 arm64e
        open('ios-mcp-arm64.dylib','wb').write(d[o:o+sz])
```

结果：686KB 单架构，`ldid -S` 签名后部署。

## 四、⭐ MCP 调用方式（不用改客户端配置）

尼尼写了个包装脚本 `tools/mcp.sh`，直接用 curl 走 JSON-RPC：

```bash
./tools/mcp.sh tools                    # 列出 46 个工具
./tools/mcp.sh shot [文件名]            # 截图 → tmp/mcp-out/*.png
./tools/mcp.sh front                    # 前台 App
./tools/mcp.sh run 'ls /tmp'            # 设备上跑命令
./tools/mcp.sh ui                       # UI 元素树
./tools/mcp.sh syslog 5                 # 系统日志 5 秒
./tools/mcp.sh call <工具> '<json参数>'  # 任意工具
```

### 协议要点

```bash
curl -X POST http://192.168.1.6:8090/mcp \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"screenshot","arguments":{}}}'
```

- **无状态**：不需要 session id，直接调
- 支持 `2025-11-25` / `2025-06-18` / `2025-03-26` 三个协议版本
- `/health` 用 GET，`/mcp` 用 POST（GET 会 405）

## 五、安装要点（可复现）

```bash
# ① 依赖确认（Dopamine 自带）
dpkg -l | grep -E "ellekit|preferenceloader"
# ii  ellekit          1.1.3
# ii  preferenceloader 2.2.8

# ② 下载 arm64 deb
curl -sL -H "Accept: application/octet-stream" -o ios-mcp.deb \
  "https://api.github.com/repos/witchan/ios-mcp/releases/assets/<asset_id>"
# 注意：github.com 直连超时，必须走 api.github.com

# ③ 传设备 + 装
sshpass -p "$PW" ssh -p 2222 mobile@192.168.1.6 "cat > /tmp/m.deb" < ios-mcp.deb
ssh ... "sudo dpkg -i /tmp/m.deb"

# ④ 提取单架构 + 改 XML plist（见上文）
# ⑤ sbreload
```
